This repository gathers the full 42 C++ piscine/module path, from `cpp00` to `cpp09`. Each module focuses on a different part of modern C++ and builds up the habits needed for the rest of the curriculum: clean compilation, object-oriented design, STL usage, templates, exceptions, and practical problem solving.

## Installation

If you want to clone the repository and start working locally, use the following steps:

1. **Clone the Repository**

```bash
git clone https://github.com/haytham-hammioui/42_CPP-MODULES_1337.git cpps
```

2. **Go to the Repository**

```bash
cd cpps
```

## Modules

- [cpp00](cpp00/README.md) - Introduction to C++, iostreams, namespaces, classes, and basic interaction.
- [cpp01](cpp01/README.md) - Memory, references, pointers, dynamic allocation, and simple class design.
- [cpp02](cpp02/README.md) - Ad-hoc polymorphism, operators, and canonical class forms.
- [cpp03](cpp03/README.md) - Inheritance and class hierarchies.
- [cpp04](cpp04/README.md) - Polymorphism, abstract classes, and deep copy behavior.
- [cpp05](cpp05/README.md) - Exceptions, forms, bureaucrats, and error handling.
- [cpp06](cpp06/README.md) - Casts, serialization, and type conversion.
- [cpp07](cpp07/README.md) - C++ templates and generic programming.
- [cpp08](cpp08/README.md) - Templated containers, iterators, and algorithms.
- [cpp09](cpp09/README.md) - STL-based problem solving, containers, and performance-oriented exercises.

## What This Repository Covers

- Core C++ syntax and project structure.
- Class design, constructors, destructors, and the Rule of Three/Five mindset.
- Polymorphism, inheritance, abstraction, and encapsulation.
- Templates, standard containers, iterators, and algorithms.
- Defensive programming with exceptions and validation.

## Usage

Most exercises follow the same workflow:

1. Enter the exercise directory.
2. Build with `make`.
3. Run the program or the provided evaluation tests.
4. Fix warnings, edge cases, and forbidden patterns.
5. Rebuild until the module is clean and correct.

For a specific module, open its README first. Each one summarizes the subject, the exercises, and the main concepts before you start coding.
